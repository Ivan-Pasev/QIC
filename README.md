# QIC — Quantum Internet Computer

QIC is an experimental sovereign cybernetic computing architecture focused on evidence-bearing state transitions, explicit authority boundaries, bounded cognitive execution, witnessed causality, sovereign federation, and progressively qualified cyber-physical operation.

> **Status:** Genesis implementation convergence. Architectural specifications exist; the public codebase is being bootstrapped from QIC-G0 onward. Do not infer operational maturity beyond explicit tests and release evidence.

## Core principles

- **Generation != Authority**
- **Proposal != Canonical Knowledge**
- **Remote State != Local Authority**
- **Decision != Physical Actuation**
- **Learning != Safety-Law Rewrite**
- **Design Generation != Physical Mutation**
- **No Accelerator Without Measured Bottleneck**
- **No Plane May Claim Operational Maturity Beyond Its Actual Evidence**

## Architecture

QIC is organized around a small trusted constitutional core and a set of explicitly bounded processors:

- **KBI** — authoritative knowledge-state processor.
- **MLCO** — bounded mission compilation/execution layer.
- **Hermes** — planner/agent that proposes but does not silently mutate canonical state.
- **Omnius** — job/resource/processor orchestrator without epistemic authority.
- **Holo / Topo / Knot** — derived semantic, graph, and structural-pathology processors.
- **Chrono** — append-only causal genealogy and witness lineage.
- **FQNP** — sovereign federation protocol where receive != admit.
- **FKC** — federated scientific/program contracts with explicit evidence, replication, local acceptance, and closure.
- **CPTG** — cyber-physical transition gate for bounded physical effects.

## Implementation sequence

The immediate goal is to build the smallest credible executable constitutional kernel before expanding the higher layers.

1. `QIC-G0` — Repository + constitutional spine
2. `QIC-G1` — Canonical serializer + digest kernel
3. `QIC-G2` — Root ontology + maturity vector
4. `QIC-G3` — Authority + capability model
5. `QIC-G4` — Transition engine + invariant gate
6. `QIC-G5` — Chrono + witness
7. `QIC-G6` — Minimal KBI
8. `QIC-G7` — Genesis CLI + verification
9. `QIC-G8` — Adversarial constitutional tests

G0–G8 collectively establish the first real `I00` implementation target.

## Maturity boundary

QIC documentation and releases distinguish at least these states:

`conceptual -> implemented -> tested -> formally modeled -> simulated -> hardware-tested -> deployed -> independently replicated`

A result produced by a simulator, accelerator, LLM, or future QPU is a computational artifact until separately admitted and evidenced under the relevant authority rules.
